# Яндекс.Маршруты — тест-анализ и тест-дизайн

## Описание проекта
Тест-анализ и тест-дизайн формы расчёта маршрута в сервисе **Яндекс.Маршруты**. Проект посвящён применению техник тест-дизайна: классы эквивалентности (КЭ) и граничные значения (ГЗ).

**Тестируемый сервис:** https://qa-routes.praktikum-services.ru/

## Задачи
- Провести тест-анализ полей формы расчёта маршрута.
- Составить классы эквивалентности и граничные значения.
- Разработать тест-кейсы на основе анализа.
- Провести тестирование и завести баг-репорты.

## Структура рабочей таблицы

| Лист | Что внутри |

| **Этап 2. КЭ и ГЗ** | Классы эквивалентности и граничные значения для 4 полей |

## Что проанализировано

### Поля формы
- **Часы** — целые числа от 0 до 23
- **Минуты** — целые числа от 0 до 59
- **Откуда** — адрес из фиксированного списка (7 адресов)
- **Куда** — адрес из фиксированного списка (7 адресов)
- **Расстояние между адресами** — равно 0 / больше 0

### Применённые техники тест-дизайна
- **Классы эквивалентности:** валидные и невалидные значения для каждого поля.
- **Граничные значения:** 0, 1, 9, 10, 23, 24 для часов; 0, 1, 59, 60 для минут; 50 символов для адреса.
- **Анализ временных интервалов:** 5 интервалов для расчёта стоимости поездки (22:01–00:00, 00:01–08:00, 08:01–12:00, 12:01–18:00, 18:01–22:00).

## Что сделано
- Проведён полный тест-анализ 4 полей формы.
- Составлены классы эквивалентности и граничные значения.
- Разработано **68 тест-кейсов** с шагами и ожидаемыми результатами.
- Проведено тестирование в Google Chrome.
- Заведено **16 баг-репортов** с приоритизацией (критический, желательный).

## Найденные баги

### Критические (8)
- **BUG2:** появляется ошибка при вводе однозначных чисел в поле «Часы».
- **BUG3:** не появляется ошибка при вводе числа 24 в поле «Часы».
- **BUG4:** не появляется ошибка при оставлении пустым поля «Часы».
- **BUG6:** появляется ошибка при вводе однозначных чисел в поле «Минуты».
- **BUG7:** не появляется ошибка при оставлении пустым поля «Минуты».
- **BUG9:** нет ошибки при оставлении пустым поля «Откуда».
- **BUG12:** нет ошибки при оставлении пустым поля «Куда».
- **BUG15:** ошибка в расчёте времени поездки.
- **BUG16:** ошибка в расчёте стоимости поездки.

### Желательные (7)
- **BUG1, BUG5:** не проставляется 0 перед однозначными числами.
- **BUG8:** неверный текст ошибки в поле «Откуда».
- **BUG10, BUG11, BUG13, BUG14:** не удаляются пробелы до/после адреса.
