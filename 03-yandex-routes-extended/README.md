# Яндекс.Маршруты — расширенное тестирование веб-приложения

## Описание проекта
Расширенное тестирование веб-приложения **Яндекс.Маршруты** (сервис каршеринга). В отличие от 2-го спринта, здесь акцент сделан на **вёрстке, логике окон и полном флоу бронирования**.

**Тестируемый сервис:** https://qa-routes.praktikum-services.ru/

## Задачи
1. Подготовить чек-лист на вёрстку формы бронирования и элементов навигационной карты.
2. Подготовить чек-лист и тест-кейсы на логику окон «Способ оплаты» и «Добавление карты».
3. Написать тест-кейсы на кнопку «Забронировать».
4. Провести тестирование и завести баг-репорты.
5. Подвести итоги (рефлексия по проекту).

## Что сделано

### 1. Чек-лист на вёрстку
- Проверка формы бронирования.
- Проверка элементов навигационной карты: иконки автомобилей и действия с ними.
- Сверка с макетами Figma и требованиями.

### 2. Чек-лист и тест-кейсы на логику окон
- Окно «Способ оплаты».
- Окно «Добавление карты».
- Тест-кейсы на кнопку «Забронировать».

### 3. Тестирование
- Прогон по составленной документации.
- Выявление багов и заведение баг-репортов.

### 4. Итоги (рефлексия)
Смешанные впечатления от продукта: много мелких некритичных багов, но после доработки получится хорошее приложение. Удалось протестировать вёрстку каршеринга, логику, формы заполнения водительских прав, способ оплаты и различные ситуации при бронировании. Продукт требует доработки — есть проблемы с привязкой карт и оформлением бронирования.
