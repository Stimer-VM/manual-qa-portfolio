# Яндекс.Метро — мобильное тестирование

## Описание проекта
Функциональное и регрессионное тестирование мобильного приложения **Яндекс.Метро** на Android после рефакторинга. Цель — проверить затронутые изменениями части продукта и убедиться, что новую версию можно заливать в стор.

## Окружение
- **Устройство:** эмулятор Honor 8
- **ОС:** Android 9.0 Pie
- **Разрешение:** 1080×1920
- **Диагональ:** 5.5"
- **Версия приложения:** v3.6
- **Инструменты:** Android Studio, ADB, logcat

## Задачи
1. Подготовить чек-лист для функционального тестирования по требованиям, затронутым рефакторингом.
2. Подготовить чек-лист для регрессионного тестирования с учётом мобильной специфики.
3. Провести тестирование.
4. Завести баг-репорты.
5. Оформить отчёт о тестировании для менеджера Марисы.

## Что сделано

### 1. Функциональное тестирование
Составлен чек-лист по требованиям, затронутым рефакторингом.

### 2. Регрессионное тестирование
Учтены мобильные особенности:
- Переключение между сетями (3G, LTE, Wi-Fi).
- Работа после восстановления связи.
- Определение геолокации.
- Работа в авиарежиме.
- Переключение между приложениями.
- Поведение при входящем звонке/уведомлении.
- Смена ориентации экрана.
- Режим энергосбережения.
- Работа при низком заряде аккумулятора.
- Обновление приложения.

### 3. Результаты тестирования
- **Всего проверок:** 194
- **Passed:** 175
- **Failed:** 19

### 4. Найденные баги
- **Блокирующие:** 1

### 5. Отчёт о тестировании
Написан отчёт для менеджера с указанием:
- Окружения и версии приложения.
- Ссылок на чек-листы и баг-репорты.
- Итогов по проверкам.
- Требования устранить блокирующий и критический баги перед публикацией в Google Play.
- Затраченного времени: 17 часов на документацию, 8 часов на тестирование.
