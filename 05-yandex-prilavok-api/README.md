# Яндекс.Прилавок — тестирование API

## Описание проекта
Тестирование API новой функциональности бэкенда **Яндекс.Прилавка**. Работа с REST API через Postman: анализ требований, проектирование тестов, проверка позитивных и негативных сценариев.

**Документация API:** ApiDoc (Яндекс.Прилавок)
**Инструмент:** Postman

## Задачи
1. Проанализировать требования к новой функциональности бэкенда.
2. Изучить документацию API в ApiDoc.
3. Спроектировать тесты в виде чек-листа.
4. Протестировать API через Postman.
5. Завести баг-репорты.
6. Написать отчёт о тестировании (дополнительное задание).

## Что сделано

### 1. Тест-анализ
- Изучены требования к новой функциональности.
- Проанализирована документация API в ApiDoc.
- Определены эндпоинты для тестирования.

### 2. Проектирование тестов
- Составлен чек-лист для покрытия функциональности.
- Применены техники тест-дизайна для API:
  - Классы эквивалентности.
  - Граничные значения.
  - Негативные сценарии.

### 3. Тестирование через Postman
- Созданы коллекции запросов.
- Проверены статус-коды ответов (200, 201, 400, 401, 404, 500).
- Проверена валидация JSON.
- Проверены заголовки и тела запросов/ответов.
- Проверена авторизация.
- Проверены негативные сценарии.

### 4. Баг-репорты
- Заведены баг-репорты на найденные дефекты API.
- Указаны шаги воспроизведения, ожидаемый и фактический результат.

### 5. Отчёт о тестировании
Написан отчёт о статусе протестированной части продукта.
