# Mesto — регрессионное тестирование и ретест багов

## Описание проекта
Регрессионное тестирование веб-приложения **Mesto** — интерактивной страницы для добавления и оценки фотографий. После внесения изменений в код нужно было убедиться, что старая функциональность не сломалась, и перепроверить ранее найденные баги.

## Задачи
- Провести регрессионное тестирование по готовым тест-кейсам.
- Выполнить ретест ранее найденных дефектов.
- Зафиксировать результаты в Google Sheets.

## Что сделано
- Проведено регрессионное тестирование всех ключевых сценариев: добавление, удаление и лайк фотографий, редактирование профиля, выход из аккаунта.
- Проведён ретест исправленных багов.
- Задокументированы результаты в таблицах.
