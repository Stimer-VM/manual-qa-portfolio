# Manual QA Portfolio

Документация по ручному тестированию учебных проектов курса **«Инженер по тестированию: от новичка до автоматизатора»** (Яндекс Практикум, 50-я когорта).

## 🛠 Инструменты
- **Баг-трекинг:** YouTrack
- **Тестовая документация:** Google Sheets, Excel
- **Перехват трафика:** Charles Proxy
- **API:** Postman
- **Мобильное:** Android Studio, ADB, logcat
- **Веб:** DevTools
